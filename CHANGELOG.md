## [Unreleased]

### Added
- `tests/patterns/EfMigrationConsistencyTest.cs` — test pattern: EF Core model/migration drift caught in CI via `dotnet ef migrations has-pending-model-changes` (exit-code gate) + full migration chain applied to an empty container (catches hand-written hallucinated SQL and migrations that only work incrementally). Traps documented: forgotten migration after an entity change, snapshot edited by hand to silence the sync check. Methodology wiring: Migrations section in `rules/AGENTS_TEMPLATE.efcore.md`, knowledge-map row.
- `tests/patterns/CharacterizationTest.cs` — test pattern: golden master for spec-less code (lost-spec calculators, implementation replacements). Deterministic boundary-first inputs with fixed seed, committed JSON outputs, refactor must reproduce them byte-for-byte; bounded tolerance for variance-prone algorithms. Traps documented: agent regenerating the golden master in the same PR as the refactor, happy-path-only recording, tolerance wider than observed variance, unpinned environment (time/culture/random). Methodology wiring: ONBOARDING.md Step 5, GLOSSARY, knowledge-map row.
- `tests/patterns/BenchmarkTest.cs` — test pattern: BenchmarkDotNet as evidence for hot-path optimizations (A/B baseline+candidate in one run, `[MemoryDiagnoser]`), CI gates only build-to-build ratios, never absolute numbers; division of roles with `AllocationBudgetTest.cs` (BDN = evidence in a PR, budget test = regression gate). Traps documented: benchmarks via `dotnet test`/Debug, "faster but allocates 3x", empty datasets, CI high-priority warnings reading as OK. Cross-ref added to `perf-test-authoring` skill exclusions.
- New trap `docs/traps/agent-behavior.md#surface-leak` + solution `docs/solutions/public-api-surface.md` — accidental public API surface changes: agent widens visibility "for convenience", renames or removes public symbols; repo tests stay green, contract consumers break at their own build. Defense in three layers: internal-by-default (fail-closed visibility), `InternalsVisibleTo` as a narrow allowlist (removes the "public for tests" excuse), `Microsoft.CodeAnalysis.PublicApiAnalyzers` with RS0016/RS0017 escalated to errors (diagnostic IDs and the `*REMOVED*` removal flow verified against the official roslyn docs; RS0026/RS0027 optional-parameter overload traps, RS0051–RS0061 internal-API tracking noted as opt-in). The `PublicAPI.Unshipped.txt` diff is the contract-change report for review — one file instead of a 2000-line diff. Working demo in DemoProject: `src/DemoProject.Domain` wired green (surface bootstrapped into Shipped, Unshipped empty as the report file) + red build-time trap `traps-src/DemoProject.Traps.PublicApi` (leaked helper → 6×RS0016, renamed+deleted methods → 4×RS0017), outside `DemoProject.sln` on purpose and verified by a new step in the `traps-guardrails` CI job. Field findings folded into the solution doc: bootstrap via `dotnet format analyzers --diagnostics RS0016` (code fix unreliable outside VS; line format has no canonical write-up — accessor-per-line properties, `Member = value -> EnumType` enums, dual record-struct ctors, trailing `!` nullability), and RS0017 severity must be escalated via csproj `<WarningsAsErrors>` because `.editorconfig` diagnostics do not reach additional-file locations. Applicability: libraries and shared contracts, not single-app deployments. Registered in the knowledge map (`docs/README.md`); Level-1 rows of README / README.ru updated; TRAPS.md gained the build-time trap section; methodology wiring: ONBOARDING.md Step 4 item, "Public API Surface" constitution add-on in `rules/AGENTS_TEMPLATE.addons.md`, review-signal block in `templates/skills/code-review/CHECKLIST.md` (unshipped diff / `*REMOVED*` / new IVT entry → contract-change flag), T9 + P10 nodes and edges in `docs/relationships.mmd`.
- New trap `docs/traps/code-quality.md#silent-culture-footguns` — culture-dependent string/parsing defaults and timeout-less regex (ReDoS) that look idiomatic in review; defense: Meziantou.Analyzer (MA0002, MA0006, MA0009, MA0011, MA0074, verified against official rule docs) with selective-enable guidance + `BannedSymbols.txt` blacklist. ### Removed
- `code-duplication` trap (`docs/traps/code-quality.md`) — removed entirely with its solution stack, following the removal of `DuplicationGuardTest`. Rationale (owner decision): literal duplication is visible in review and cheap to fix; it does not merit a dedicated trap + guard entry, and its automated regex guard silently rots. Duplication stays covered where it belongs: semantic-duplication check in the `code-review` skill and the tech-debt audit. Dependency Drift trap loses the comparison table (referenced the removed trap). Knowledge-map row removed.
- `tests/patterns/DuplicationGuardTest.cs` (+ both demo copies, DemoProject and MinimalApi) — the only guard built entirely on regex over `.cs` sources. Regex-over-source silently rots: any legitimate refactor of the watched expression turns the guard into a vacuous green test (the exact failure mode this repo flags in `solutions/ai-patterns.md` §2 Roslyn-first). The `code-duplication` trap stays; its solution is now structural: one owner module + architecture test forbidding reimplementation, semantic-duplication check in the `code-review` skill, `BR-###` numbered rules. Skill cross-references (code-review, complexity-audit, tech-debt-audit) and the knowledge map repointed; MinimalApi test-count ratchet baseline adjusted. Owner-approved exception to the "do not remove template examples" agent rule.
- `docs/TRANSLATION_PLAN.md` — translation is complete; the working plan document was deleted (the bilingual READMEs are the result).
